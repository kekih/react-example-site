# React Example Site

Простой и современный пример одностраничного сайта на **React 18 + Vite**.

## Что внутри

- Адаптивный лендинг (Header, Hero, Features, About, Contact, Footer)
- CSS Modules
- Чистый и понятный код
- Готов к деплою

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/kekih/react-example-site.git
cd react-example-site

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

## Структура проекта

```
src/

│   ├── Features.jsx + .module.css

│   ├── Contact.jsx + .module.css
│   └── Footer.jsx + .module.css

```

## Технологии

- React 18
- Vite 5
